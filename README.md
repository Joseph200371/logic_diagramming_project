# Logic Diagramming Project (Python)

Repositorio de prácticas y proyecto final para la materia **Diagramación Lógica**.
El objetivo es desarrollar pensamiento algorítmico y resolver problemas utilizando Python.

---

## 📁 Project Structure

```
logic_diagramming_project/
│
├── src/                    # Código principal organizado por unidades
│   ├── fundamentals/       # Variables, tipos de datos, input/output
│   ├── control_flow/       # Condicionales (if, elif, lógica)
│   ├── iteration/          # Bucles (for, while)
│   └── final_project/      # Proyecto integrador
│
├── exercises/              # Ejercicios prácticos

├── .gitignore

```

## 🚀 Getting Started

### 1. Clonar el repositorio

```bash
git clone <repo-url>
cd logic_diagramming_project
```

### 2. (Opcional) Crear entorno virtual

```bash
python -m venv venv
```

Activar entorno:

* Windows:

```bash
venv\Scripts\activate
```

* Linux / Mac:

```bash
source venv/bin/activate
```

### 3. Instalar dependencias

```bash
pip install -r requirements.txt
```

---

## ▶️ Uso

Ejecutar archivos desde la terminal:
